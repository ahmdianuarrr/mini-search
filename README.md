# mini search
mesin pencari dokumen dengan backend c++

## progres yang sudah jadi
- halaman web dasar (html dan css)
- Tokenizer: memecah teks menjadi kata (huruf kecil, tanpa tanda baca)
- Inverted index: mencatat kata ada di dokumen mana
  
## Rencana berikutnya
- Pencarian interaktif di terminal
- Membaca dokumen dari file
- Pencarian beberapa kata
- Peringkat hasil
- Menghubungkan backend C++ dengan halaman web

## Struktur folder
- `src/` : kode C++ (backend)
- `web/` : tampilan web (frontend)
